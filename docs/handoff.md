# 自动转服与大厅名额释放（Beta）

网易玩家使用原版客户端正常进房，程序自动转到游戏后端，并在交接时释放网易大厅名额。无需玩家安装插件或手动输入地址；仍可能出现两段加载画面。

## 配置

1. 将 NEMCBridge 所在机器的 **UDP 19441** 映射到公网，或配置支持 UDP 的内网穿透；樱花 FRP 只需一条 UDP 隧道。
2. 在「国际服 → 公网网关」填写 `域名或IP:公网端口`，例如 `gateway.example.com:24185`。多个国际服共用此入口。
3. 编辑需要启用的国际服，开启 **突破10人限制（Beta）**。Bedrock 地址仍填实际后端，不要改成公网网关。

未填写网关时开关禁用；清空网关会关闭各国际服的 Beta 开关。修改全局入口前须停止所有房间，修改单个国际服前须停止该服。

| 地址 | 用途 |
| --- | --- |
| 本机 UDP 19441 | 穿透隧道的本地目标 |
| 网关公网地址及端口 | 填入「公网网关」，供玩家转服 |
| 游戏后端地址 | 填入国际服的「Bedrock 地址」，由 NEMCBridge 访问 |

同机穿透客户端可转发到 `127.0.0.1:19441`；容器或另一台机器上的穿透客户端，需让其能访问 NEMCBridge 的监听地址。隧道来源不在本机自动识别的可信网段时，在高级 `handoff.allowed_networks` 中明确允许其实际来源网段，不要配置 `/0`。高级 `handoff.listen_port` 可覆盖默认端口。

**只穿透游戏 UDP 端口，不要穿透 18321 管理控制台。HTTP／TCP 隧道不能替代 UDP。**

## 开房前检测

程序会检测公网网关并显示失败原因。端口冲突、映射到错误服务等问题必须先处理；本机公网回环或出站 UDP 不通时，玩家可能仍能从外网连接，可确认后继续并用实际客户端验证。检测通过不等于所有玩家的网络均可达。

## 范围与限制

- 网关校验交接身份，并将会话路由到对应国际服；多个账号、房间共用同一固定端口，停止一个房间不会关闭其他房间的网关。
- 默认每房间最多 128 个交接／在线会话，这是会话保护上限，不是已验证的玩家容量。
- 已完成原版手机转服和大厅名额释放验证；**超过 9 位访客同时在线尚未实测，不承诺无限人数**。实际容量还取决于后端、网络与机器资源。
- 关闭 Beta 开关可恢复持续占用网易房间连接的普通桥接方式。升级保留原配置；旧的相同公网地址自动迁移为全局 `transfer_address`，冲突地址须手动指定。

## 转服后移动前冲的兼容设置

若开启「突破10人限制（Beta）」后出现短暂停顿再向前跳，且后端是协议 **898** 的 BDS，先确认后端 `server.properties` 中已使用 `block-network-ids-are-hashes=true`。可给 **NEMCBridge 的启动进程**设置环境变量 `NEMCBRIDGE_HANDOFF_NATIVE_CACHE_UPSTREAM`，值必须与控制台中该国际服的「Bedrock 地址」完全一致，例如 `127.0.0.1:19132`。重启 NEMCBridge 并重新进房测试。

只为已经确认使用原生哈希 ID 的后端启用，不要用于需要转换方块表的后端。其他后端和未设置该变量的部署仍沿用原行为。若启用后无法进房，删除环境变量并重启；在无法使用兼容设置时，关闭该服的 Beta 开关可临时规避。

目前只完成了 BDS 1.21.132.3 的原版网易客户端复测，不代表其他版本或后端都存在或解决此现象。
