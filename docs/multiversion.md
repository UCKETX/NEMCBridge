## 转换范围

链路为「网易 898 ↔ 标准 898 ↔ 后端 859/860/898/924/944/975/1001/2168/2169/2193/2225」。登录和 RequestNetworkSettings 使用自动探测到的后端协议。后端游戏 AES 加密仍在桥接中终止，转换发生在明文阶段，网易侧继续使用原有 WebRTC 传输。

- 860 StartGame 移除旧 TickDeathSystemsEnabled 标志，保留其他世界数据，再进行网易世界扩展转换。
- 双向转换 Text、CommandRequest、CommandOutput、AvailableCommands、Animate、Interact，以及资源包栈、药水效果、事件、调试标记和镜头辅助预设的不同字段布局。
- AvailableCommands 支持 1、2、4 字节的旧枚举索引、旧权限编码及链式子命令。898 命令的 Latest 按 Endweave 的旧版适配映射到命令语法版本 45（CloneExtraBlockFilterFix），避免继续使用方块扁平化之前的版本 42。
- 音效保留 0–565，旧版 Undefined 566 转为 898 的 578；实体生成和更新中的 HeartbeatSoundEvent 同步映射，仅改对应整数的原始字节，保留物品额外数据和其他 metadata。发往旧后端的新增音效 566–577 不转发。
- 发往旧后端的新版 ServerboundDataStore（332）明确丢弃；混合批次中的其他包保留，全部丢弃时不发送空批次，也不递增后端加密计数。
- 旧划船动画转为对应船桨时间的实体 metadata；其视觉效果仍需真实客户端复验。新版 SwingSource 不传给旧后端。
- 860 资源包栈的 BehaviourPacks 字段不传入已经删除该字段的 898 布局；TexturePacks、实验设置和原有网易预加载流程保留。客户端行为包与脚本不因此获得兼容保证。
- 原版 860/898 使用相同方块调色板；继续使用已有哈希 ID 路径和 Geyser 顺序 ID 转换。物品使用后端 ItemRegistry 声明的编号。未改变布局的数据包保持原字节，保留子客户端头、压缩方式及物品 NBT。

新增内容使用经过审核的原版内容映射；不对任意模组或未知协议自动套用映射。26.30 以后的新增外观范围见下节。


## 26.30–26.60 验证（2026-11-02）

26.30.5、26.40.8、26.45.1、26.51.1 和 26.60.6 分别通过 8 个顶层实服测试：登录与世界、缓存区块、WebRTC 世界、直连/WebRTC 中文聊天、直连/WebRTC 命令，以及桥接直接资源包下载。下载覆盖普通协商和网易提前响应的两条路径，逐包校验 SHA256、资源栈及 35 个独立物品注册。26.20 另做登录、缓存地形和 WebRTC 回归。这些使用合成网易协议客户端；新版本仍需安卓实际渲染、移动、挖掘和物品交互验收。

26.60 后端使用 NetherNet。BDS 配置 `transport=nethernet`、`online-mode=false`、`block-network-ids-are-hashes=true`，桥接服务器地址填写 `http://主机:端口`，例如 `http://127.0.0.1:19132`。这个端口用于 HTTP 信令；BDS 的 `server-udp-ports` 还需允许桥接访问。HTTPS 地址仅用于已配置有效 TLS 的信令端点。旧版本 RakNet 继续填写 `主机:端口`。本轮 26.30/26.40/26.45 验证的是 RakNet；不将旧版 NetherNet 的信令格式视为已兼容。

- 采用固定上游提交的独立协议编解码，补齐资源响应编号、配方分组、实体 metadata/输入标志、皮肤颜色、命令参数及二维高度图的语义转换。NetherNet 登录握手验签后发送明文游戏层确认，由 DTLS 保护传输；RakNet 仍使用原有 AES。
- 金蒲公英、硫磺/朱砂系列、硫磺怪和幼年模型继续使用已有三包结构。资源按协议目录选择、按 SHA256 缓存，相同文件跨版本复用缓存，服主不用放包，国际版直连玩家不会收到桥接注入的包。
- 0.8.0 建筑资源包新增 16 色混凝土与 16 色羊毛的楼梯、台阶、双层台阶，以及白杨木板、楼梯、台阶、双层台阶：共 100 个方块定义、1453 个后端状态，使用 33 张固定来源的官方贴图。仅协议 2168 及以上且选中匹配资源包时启用，保留原版材料的外观和后端物品身份。包括倒置台阶/楼梯与邻接转角处理；自动化注册、状态回传和资源依赖检查通过，真实网易渲染仍需逐项验收。
- 白杨栅栏、栅栏门等其余木制品，床、冰晶等仍使用旧版替代外观；原木、木头、去皮木及三色树叶的 0.8.2 独立外观已通过手机验收。门和活板门经 0.8.6 贴图修正及 `.28` 交互修正后，用户已确认正常；声音仍未单独确认。冰霜怪、冰弹和坐垫实体暂分别使用流浪者、雪球和盔甲架外观。新工作站界面、特殊能力和自定义脚本不属于本轮已验证范围。
- 26.60 的玻璃板、栅栏、楼梯及红石新增连接状态映射回旧客户端状态。硫磺系列的新状态继续复用独立外观；碰撞与交互以 BDS 为准。

协议来源：Sandertv/gophertunnel 的固定提交见 `scripts/generate_protocol_schemas.py`，各版本保留 MIT LICENSE。内容表来源：GeyserMC/Geyser `64bb3993b4beef6743af0ab76ee5dfc8e67a0d21` 的 release 方块/物品表；使用 `scripts/extend_content_fallback.py` 生成并检查状态匹配，拒绝未经审核的内容。实服日志在忽略目录 `runtime/compat-2660/`，不包含用户令牌或私钥。

## 验证状态（2026-11-01）

在独立、无生产存档的官方 BDS 测试世界中，网易侧始终使用 898 格式的合成测试客户端，859、860、898、924、944、975 后端均通过：

- RakNet 网络设置、离线身份重签与 AES 加密登录；WebRTC → RakNet 网络设置往返。
- StartGame、权限、玩家初始化、区块和子区块传输，包含 blob 缓存路径。
- BDS 直连链路及本地 WebRTC 链路的中文 / emoji 聊天；连续正确和错误命令后保持连接。
- 每次会话 96 次网易动作，随后三次成功命令回执。
- 两个资源包、超过 1 MiB 的多分片下载、SHA256 和 ZIP 内容校验；标准请求和网易提前响应下载；内置经典材质预加载与后端资源包合并，最后收到 StartGame。

新转换层另有来自未修改 gophertunnel v1.51.1 编码器的 51 个固定样本，覆盖三种枚举索引宽度、命令来源及输出类型；对可逆字段要求旧样本 → 898 解码 → 旧样本字节完全一致。同一生成器再用 v1.51.0（859）运行，51 个样本全部与 860 逐字节相同。另有音效边界、四种实体包、32/64 位心跳音效 metadata、任意物品额外数据与丢包后的 AES 计数回归。10 秒模糊测试通过。主源码的单元测试和 `go vet` 通过。

以上不等于真实网易 3.10 客户端实机验收。仍需用网易客户端逐项复验进服、移动、挖放方块、背包合成、骑乘、皮肤、资源渲染以及自定义实体与组件。Geyser 的跨版本实机结果也待复验。

26.10/26.20 另外通过了独立账号存档测试：两个账号共用原始客户端 UUID 时背包和位置仍隔离，改名与更换会话 UUID 后重新登录仍读回各自的 7 个钻石 / 3 个绿宝石和原位置。测试状态由隔离服务器控制台设置，客户端保持成员权限。

配方书中涉及替代物品的显式配方暂时隐藏，未受影响的配方原字节保留；不将普通旧物品冒充新材料。带新规则的合成 UI、桶交互、实体动画与特殊玩法尚未完整模拟，仍需真实网易客户端验收。未知内容和自定义模组不进行猜测替换。

官方 BDS 1.26.10.4 / 1.26.20.5 已验证金蒲公英替代显示、物品回传、背包 9 个拆分为 5+4 个并移动，以及重连后仍保留原新版物品。客户端使用合成网易协议测试器，尚不构成真实网易客户端视觉验收。

回归覆盖独立哈希向量、全部替代目标存在于旧版调色板、物品原字节往返、跨连接/伪造标记拒绝、旧物品不误转换、负坐标交互恢复、两层方块更新、空区块和跨维度清理、配方过滤及双向并发；10 秒模糊测试约 4.6 万次执行通过。固定源、摘要与再生成方式见 `internal/netease/assets/README.md`。
