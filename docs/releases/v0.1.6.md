# NEMCBridge v0.1.6

## 更新内容

- 支持同时开多个本地联机房间（最多 8 个），全部进入同一个世界。每个网易房间最多 9 名玩家，多开房间即可接入更多网易玩家。
- 每个房间使用一个机器人令牌，控制台“机器人令牌”可逐个添加、替换和移除；开房后列出每个房间的房间号、状态和人数，“复制房间号”复制全部房间号。
- 各房间独立鉴权、开房和重连，一个房间掉线不影响其他房间；同一个令牌不能用于两个房间。
- 控制台的保存、启动失败提示不再被自动刷新冲掉，成功提示改为绿色。
- 修复手机上部分图标显示为彩色 emoji，以及设置与日志卡片底边不对齐。

**多房间提示：**每个房间需要一个在 FGAuth 中指定了不同网易账号的令牌，需使用 FGAuth v1.0.13 或更新版本。同一账号同时开两个房间会互相挤下线。BDS 的 `max-players` 需容纳所有房间的玩家。详见[部署指南](https://github.com/UCKETX/NEMCBridge/blob/main/docs/setup.md#多个房间)。

单房间用户无需改动，原有令牌和配置继续使用。

## 启动

1. 先运行自己的 Bedrock 服务器。
2. 解压：Windows 双击 `NEMCBridge.exe`；Linux/macOS 在解压目录执行：

   ```sh
   chmod +x NEMCBridge
   ./NEMCBridge -data-dir ./data
   ```

3. 打开 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，其他设备使用终端显示的局域网地址。
4. 使用 `admin` 和首次启动终端显示的密码登录，填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、机器人令牌和后端地址，保存后开房。

升级时先退出旧程序，替换可执行文件并继续使用原数据目录。
