# NEMCBridge v0.1.5

## 更新内容

- 管理控制台全新界面：登录页与控制台采用与官网一致的配色和像素风格。
- 状态标签按阶段着色（在线、鉴权中、等待重连、服务器离线），控制台与程序断开时显示「控制台连接中断」。
- 房间设置按连接、房间、选项分组，开关项改为切换按钮；机器人令牌显示「已保存」或「尚未设置」。
- 运行日志改为终端样式，Debug 行变暗，失败、断开、超时等消息高亮显示。
- 控制台新增网站图标。
- 项目官网上线：https://ucketx.github.io/NEMCBridge/

本版本不涉及协议与存档变化，升级时直接替换可执行文件即可。

## 启动

1. 先运行自己的 Bedrock 服务器。
2. 解压：Windows 双击 `NEMCBridge.exe`；Linux/macOS 在解压目录执行：

   ```sh
   chmod +x NEMCBridge
   ./NEMCBridge -data-dir ./data
   ```

3. 打开 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，其他设备使用终端显示的局域网地址。
4. 使用 `admin` 和首次启动终端显示的密码登录，填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、机器人令牌和后端地址，保存后开房。

升级时先退出旧程序，替换可执行文件并继续使用原数据目录。
