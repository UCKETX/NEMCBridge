# NEMCBridge v0.1.4

## 更新内容

- 修复网易普通成员显示为访客、无法破坏和放置方块的问题。
- 修复不同网易账号共用背包和位置；每个账号使用独立存档，重进或改名后保留数据。
- 修复游戏内玩家列表中自己的昵称重复显示。
- 房间人数调整为 2–10 人，包含房主机器人，旧配置自动修正。
- 增加 Debug 权限诊断及真实 BDS 的权限、存档隔离回归测试。

**升级提示：**先备份后端世界。新版网易玩家将使用按账号隔离的存档；此前共用的玩家数据仍保留，不会自动分配给某个账号，需要时由管理员恢复或分配旧物品。

## 启动

1. 先运行自己的 Bedrock 服务器。
2. 解压：Windows 双击 `NEMCBridge.exe`；Linux/macOS 在解压目录执行：

   ```sh
   chmod +x NEMCBridge
   ./NEMCBridge -data-dir ./data
   ```

3. 打开 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，其他设备使用终端显示的局域网地址。
4. 使用 `admin` 和首次启动终端显示的密码登录，填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、机器人令牌和后端地址，保存后开房。

升级时先退出旧程序，替换可执行文件并继续使用原数据目录。
