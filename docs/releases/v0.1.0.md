# NEMCBridge v0.1.0

## 功能

- 网易版与国际版 Bedrock 玩家进入同一个 BDS 世界。
- 支持世界加载、方块交互、双向聊天和皮肤互显。
- 机器人持续开房，掉线自动重连。
- 内置 Web 管理页面，支持局域网访问，终端显示访问地址。

`.sha256` 是压缩包校验文件，不是启动程序。

## 启动

1. 先运行自己的 Bedrock 服务器。
2. 解压下载文件：Windows 双击 `NEMCBridge.exe`；Linux/macOS 在解压目录执行：

   ```sh
   chmod +x NEMCBridge
   ./NEMCBridge -data-dir ./data
   ```

3. 本机打开 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，其他设备使用终端显示的局域网地址。
4. 填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、自己的机器人令牌和后端地址，保存后点击「开房」。
5. 网易玩家搜索房间号加入，国际版 Bedrock 玩家直接连接后端服务器。

控制台默认监听 `0.0.0.0:18321`，没有登录认证，请仅向可信网络开放。后端设置及兼容版本见 [部署指南](https://github.com/UCKETX/NEMCBridge/blob/main/docs/setup.md)。
