# NEMCBridge v0.1.0

连接网易版与国际版 Minecraft Bedrock 的联机桥接工具。

## 功能

- 使用 FGAuth 登录房主机器人，创建网易本地联机房间，将玩家转发到已有的 BDS 世界。
- 支持区块加载、方块破坏与放置、双向文字聊天和皮肤互显。
- 内置 Web 控制台，管理后端、房间参数、令牌及连接状态；掉线后自动重试开房。
- 兼容大批次与 WebRTC 分片，提供本机相同令牌的会话互斥。
- Windows 使用 DPAPI 保存令牌，Linux/macOS 使用 0600 文件权限保护。

## 下载与启动

提供 Windows、Linux、macOS 的 amd64 和 arm64 压缩包，每个包附 SHA256 校验文件。

Windows 解压后启动 `NEMCBridge.exe`；Linux/macOS 运行 `./NEMCBridge -data-dir ./data`。控制台默认地址为 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、自己的令牌和后端地址后开房。

发布包附使用说明、配置示例、项目及第三方许可证；不含机器人凭据、个人配置、BDS 服务器、世界或日志。

## 兼容范围

已验证：网易客户端 3.9.41.300665、房间版本 1.21.120.0 / 协议 42、BDS 1.21.124.2 / 游戏协议 860、国际版 Bedrock 1.21.124。Windows 已完成客户端实测；Linux/macOS 完成构建与自动测试。

后端需设置 `online-mode=false`、`compression-algorithm=zlib` 和 `block-network-ids-are-hashes=true`。后端身份不代表 Xbox 认证，请按访问范围配置网络和游戏权限。

网易端跳过后端资源包与行为包，依赖包的自定义内容可能无法正常显示；其他版本、特殊皮肤和模组内容需要另行验证。
