# LobbyKeeper v0.1.1

## 更新内容

- 修复双向聊天协议，支持中文和 emoji，避免国际版发言导致网易玩家掉线。
- 补齐网易皮肤确认包及玩家生成字段；根据已有实机验证记录，皮肤互显已正常。
- 修复原 2MB 游戏批次限制和超过 255 个片段时的消息边界错误。
- 加入本机同令牌会话互斥，减少重复登录造成的房间断开。
- 网易玩家跳过服务端资源包和行为包，解决资源包加载失败而无法进入的问题；国际版直连 BDS 不受影响。
- 按职责整理 `internal` 包，文档归入 `docs`、工具归入 `scripts`，移除临时诊断和上游示例。
- 修复整理目录后 Windows 启动、停止、构建、Bedrock 下载及发布打包的路径。

## 下载与使用

提供 Windows、Linux、macOS 的 amd64 和 arm64 压缩包，各附 SHA256 校验文件。Windows 选 `.zip`，Linux/macOS 选 `.tar.gz`。

发布包自带 Web 控制台、使用说明及依赖许可证；不包含机器人令牌、配置、日志、Bedrock 服务器或世界。升级时保留自己的数据目录，正常关闭旧挂服机后替换可执行文件。

已实测组合：网易 3.9.41.300665、房间协议 42、BDS 1.21.124.2（游戏协议 860）。其他客户端版本需要另行验证。服务器资源包不会传给网易端，依赖包的自定义内容需客户端另行支持。
