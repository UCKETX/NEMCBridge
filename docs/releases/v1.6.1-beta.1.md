# NEMCBridge v1.6.1-beta.1 · 玩家真实 IP 透传与 PROXY Protocol v2

> 本版本为 **Beta 预发布版**，控制台一键更新默认跳过预发布版本；需要体验和测试的服主请从本页手动下载。

### 新增
- **玩家真实 IP 透传（多通道开箱即用）**：解决 NEMCBridge 本机转发时后端仅看到 `127.0.0.1` 或桥接内网 IP 的问题（[#3](https://github.com/UCKETX/NEMCBridge/issues/3)）：
  - **登录 `ClientData` 字段**：向后端发送的 `Login` `ClientData` JWT 自动写入 `ClientIP`（字符串）与 `ClientPort`（端口），并强制清除客户端自带同名字段防止伪造，覆盖协议 859–2225。
  - **结构化 JSON 文件**：在登录包发往后端前原子写入 `logs/player_ips.json`（权限 `0600`），格式为 `{玩家名: {ip, port, time, uid, uuid, xuid, source, server, online}}`，插件在登录事件即可无竞态读取；支持重连会话隔离、重启清理在线状态与离线历史上限裁剪。
  - **运行日志记录**：在 `logs/keeper.log` 与控制台日志输出 `玩家 <名称> 来自 <IP>:<端口>`。
- **UDP HAProxy PROXY Protocol v2（按国际服可选开启）**：
  - 在「国际服 → 编辑」新增 **PROXY Protocol v2** 开关（配置项 `proxy_protocol`，默认关闭），面向原生支持 UDP 代理协议的后端（如 Geyser、WaterdogPE 等），无需修改插件即可在后端日志与现有插件中直接显示玩家真实 IP。
  - 支持 IPv6 玩家连入 IPv4 后端（自动编码 `UDP6` + IPv4 映射目标地址），并限制握手 MTU 避免分片；不支持原版 BDS 或 NetherNet (`http://`) 地址。
- **自动转服与穿透 IP 保留**：通过自动转服／选服大厅且公网网关前有 FRP 等本机或私网穿透时，自动回退保留入口阶段 WebRTC 获取的玩家真实地址；若玩家经远程 TURN 中继建连，不会误报 TURN 服务器 IP。

### 优化
- **官网与文档新域名**：控制台「关于」页与主文档链接更新为 [https://nemcbridge.ucket.top/](https://nemcbridge.ucket.top/)。

### Geyser 启用 PROXY Protocol v2 注意事项
- 仅在 Geyser `config.yml` 的 `advanced.bedrock` 下开启 `use-haproxy-protocol: true` 并配置 `haproxy-protocol-whitelisted-ips`（填写 NEMCBridge 所在主机 IP）；Geyser-Spigot 插件版在 `use-direct-connection: true` 下请保持 `advanced.java.use-haproxy-protocol: false`。
- Geyser 开启该项后，对应 UDP 端口只接收带 PROXY 头的连接，未经过代理直连该端口的国际版客户端会被丢弃。
