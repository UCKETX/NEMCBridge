# NEMCBridge v1.6.1 · 多平台通知推送、QQ 群公告实时维护与玩家真实 IP 透传

`v1.6.1` 正式发布，带来全新解耦的**多平台通知中心**（含 QQ 群公告自动更新与按事件自定义模板），并将 `v1.6.1-beta.1` 的**玩家真实 IP 透传**与 **UDP PROXY Protocol v2** 正式合并上线。

### 新增：多平台通知中心

在 Web 控制台新增独立 **「通知」** 管理页，支持创建多个互不干扰的推送通道（例如玩家群播报开房/换号、服主手机收离线告警），所有配置保存即时生效，无需停房：

- **8 大平台开箱即用**：内置 **OneBot v11（QQ 群 / 私聊）**、**飞书 / Lark**、**钉钉（加签）**、**企业微信**、**Discord**、**Telegram（支持反代）**、**Bark（iOS）** 与 **通用 JSON（自定义 Header + HMAC-SHA256 签名）**；粘贴链接自动识别平台并附带官方配置入口。
- **8 类事件与选服大厅感知路由**：
  - 支持房间启动、房间停止、房间号变化、国际服离线 / 恢复、开房连续异常告警、玩家加入 / 离开、房间人数已满、新好友申请，提供「玩家群播报」「服主告警」快捷勾选。
  - **选服大厅智能去重**：大厅房间的开房 / 换号 / 停房事件按通道去重（同一通道勾选多服或全部服仅发 1 次，不同群独立通道各自送达不漏发），标题自动显示选服大厅名；玩家上下线与服务器离线保持精确按单服路由。
- **QQ 群公告实时维护（OneBot 群）**：
  - 首次开房自动发布群公告，后续开房、换号、停房自动替换更新旧公告（通过 `_get_group_notice` / `_send_group_notice` / `_del_group_notice` 仅清理本程序维护的历史公告，`notice_id` 持久化于 `onebot_notices.json`，绝不误删管理员公告）。
  - 多个国际服或多个通道指向同一个 QQ 群时自动合并维护**唯一一条**实时房间号公告。
  - 支持自定义群公告模板与实时预览，既可用 `{{rooms}}` 自动汇总全部在线房间，也支持 `{{room_id:服务器名或大厅名}}` / `{{room_password:服务器名或大厅名}}` 在不同段落拆开引用指定服房间号。
- **各平台原生增强能力**：
  - **OneBot 群 / Discord / 飞书 / 钉钉**：支持配置 `@全体` / `@指定成员或角色`。
  - **Bark（iOS）**：开房 / 换号下拉一键复制房间号，离线 / 异常自动触发时效性通知，支持自定义铃声、自定义图标与告警持续响铃 30 秒。
  - **Telegram**：支持超级群话题 ID（`message_thread_id`）、静默推送（`disable_notification`），房间号与密码自动用 `<code>` 包裹支持点按复制。
- **按事件自定义消息模板**：10 类具体事件各自独立配置模板，预填默认文案、上下文变量一键插入、实时预览与一键恢复默认；测试通知始终保持单行精简格式。
- **隐私保护与推送记录**：房间密码、玩家真实 IP 默认关闭并按通道独立控制；`logs/status.json` 自动脱敏所有 Webhook 链接、密钥与请求头；右上角「推送记录」弹窗保留最近 30 条投递状态与耗时，支持一键筛选失败记录。

### 新增：玩家真实 IP 透传与 PROXY Protocol v2

解决 NEMCBridge 本机转发时后端仅看到 `127.0.0.1` 或桥接内网 IP 的问题（[#3](https://github.com/UCKETX/NEMCBridge/issues/3)）：

- **登录 `ClientData` 注入**：向后端发送的 `Login` `ClientData` JWT 自动写入防伪造的 `ClientIP`（字符串）与 `ClientPort`（端口），覆盖协议 `859–2225`。
- **结构化文件与日志**：登录前原子写入 `logs/player_ips.json`（权限 `0600`），格式为 `{玩家名: {ip, port, time, uid, uuid, xuid, source, server, online}}`；并在 `logs/keeper.log` 与控制台输出 `玩家 <名称> 来自 <IP>:<端口>`。
- **UDP HAProxy PROXY Protocol v2（按国际服可选开启）**：在「国际服 → 编辑」开启 `proxy_protocol` 后，Geyser、WaterdogPE 等兼容后端无需修改插件即可原生显示玩家真实 IP（支持 IPv6 玩家连入 IPv4 后端；不支持原版 BDS 或 NetherNet `http://` 地址）。
- **穿透与中继边界处理**：自动转服配合本机/私网穿透（如 FRP）时自动回退保留入口 WebRTC 获取的玩家真实地址；经远程 TURN 中继建连时不误报 TURN 节点 IP。

### Geyser 启用 PROXY Protocol v2 注意事项
- 仅在 Geyser `config.yml` 的 `advanced.bedrock` 下开启 `use-haproxy-protocol: true` 并配置 `haproxy-protocol-whitelisted-ips`（填写 NEMCBridge 所在主机 IP）；Geyser-Spigot 插件版在 `use-direct-connection: true` 下请保持 `advanced.java.use-haproxy-protocol: false`。
- Geyser 开启该项后，对应 UDP 端口只接收带 PROXY 头的连接，未经代理直连该端口的国际版客户端会被丢弃。
