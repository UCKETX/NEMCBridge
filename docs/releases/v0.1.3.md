# NEMCBridge v0.1.3

## 更新内容

- 新增自动同意机器人好友申请，默认每 30 秒检查，控制台可关闭；修复好友接口签名错误码 22。
- 修复 Linux 连接房间节点时的 UDP `message too long` 错误。
- 修复网易玩家使用命令导致断线。
- 网易玩家 XUID 为空时生成固定的兼容 ID，方便后端识别；该 ID 不是微软分配的 Xbox XUID。
- 默认精简运行日志，增加可即时切换的 Debug 模式。
- 整理源码及开发目录，构建产物、配置和日志集中存放。

## 启动

1. 先运行自己的 Bedrock 服务器。
2. 解压下载文件：Windows 双击 `NEMCBridge.exe`；Linux/macOS 在解压目录执行：

   ```sh
   chmod +x NEMCBridge
   ./NEMCBridge -data-dir ./data
   ```

3. 本机打开 [http://127.0.0.1:18321/](http://127.0.0.1:18321/)，其他设备使用终端显示的局域网地址。
4. 使用账号 `admin` 和首次启动终端显示的随机密码登录，填写 [FGAuth 验证服务器](https://fgauth.ucket.top)、机器人令牌和后端地址，保存后开房。

升级时先退出旧程序，替换可执行文件并保留原数据目录，启动时继续指定该目录。默认启用自动同意好友申请，可在停止房间后通过控制台关闭。
