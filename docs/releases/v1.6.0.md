# NEMCBridge v1.6.0 · 选服大厅与进房体验优化

### 新增
- **选服大厅**：一个网易房间可以连接多个国际服。玩家进房后在游戏内选服，选好后自动转入目标服务器。服主可以在控制台添加、移除和排序目标服。
- **在线状态提示**：已确认在线的服务器显示绿色，离线服务器显示红色并标记「离线」，点击不会转服。
- **控制台改版**：概览页集中展示网易房间与国际服的连接关系，桥接页统一管理绑定。运行日志新增筛选、搜索、复制和下载，设置页新增「关于」卡片。

### 修复与优化
- 网易访客资料直查遇到网络故障时，改由 FGAuth 核验同一个 UID。确认房主会话过期时，支持在原房间尝试恢复会话。
- 自动转服沿用首次核验的身份，不重复查询；修复部分转服后误显示 UID 的问题，并为可识别的进房失败提供更具体的提示。
- 修复部分新版后端删除记分板条目时导致的断线，改进混合群系区块的兼容性，保留原有群系分布。
- 运行日志支持自动轮转；安装包精简，保留快速启动说明、示例配置和许可证。
