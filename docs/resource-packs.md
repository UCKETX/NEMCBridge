**默认通过内置组件完成预加载，再下载后端资源包；经典材质本身不加入实际加载栈。** 不需要勾选开关、创建原生房间、运行导入命令或复制配置文件。网页已移除材质相关开关，旧配置也会自动启用。

当前自制材质仍依赖原生组件预加载上下文，程序已内置「经典材质」的无密钥组件编号和协商配置。玩家客户端通过网易组件流程下载经典材质；程序本身不打包第三方材质文件。程序合并原生与后端两份列表，各资源保留自己的 UUID、版本和内容密钥，不把自制文件伪装成商城组件。无需修改网易客户端，也无需在 iOS 手动导入 `.mcpack`。

此前「彩虹物品栏」预加载及内置经典材质预加载已通过实际 iOS 测试。用户后续确认经典材质会使铜傀儡物品透明，因此当前内置配置保留组件编号、下载声明和网易扩展，但从实际资源加载栈中移除经典材质 UUID `050ac25f-3124-4acb-ad16-64b779f8255f`，让这些物品使用客户端原版资源或后端材质。该调整已通过协议回归测试和真实 BDS/WebRTC 后端资源下载、校验及世界初始化测试，网易实机的铜傀儡显示及后端材质加载仍需验证。自定义导入配置会原样使用；若仍启用了经典材质，将 `netease_resource_packs` 改为 `false`，重新开房并让玩家重新加入。

## 加载后端自制材质

1. 先在 BDS 安装材质包并为世界启用：包目录放入 `resource_packs/`，在 `worlds/<level-name>/world_resource_packs.json` 中填写其 manifest 的 UUID 和版本。使用 `.mcpack` 时先解压成包目录；确认国际版直连能正常显示。
2. 正常启动 NEMCBridge 并开房；材质会自动加载。更新后端世界使用的包后，重新开房以供新连接下载。
3. 网易玩家重新加入，等待经典材质预加载和后端材质下载、加载完成。检查实际贴图，并退出重新加入验证。首次下载较大资源可能需要较长时间。

JSON 配置对应：

```json
{
  "forward_resource_packs": true,
  "netease_resource_packs": false
}
```

不会修改 BDS 配置或世界。旧配置中的 `forward_resource_packs: false` 会自动升级为 `true`。缺少导入文件时直接使用内置配置，不再因缺少 `netease-resource-profile.json` 拒绝开房。

仍处于实验阶段：普通静态贴图和一套现有服务器资源已通过实际进服验证；该服务器的行为包随测试世界启用，但脚本、枪械交互、自定义方块/实体等全部功能尚未逐项验证，也不代表任意 PBR/光影和加密商城包兼容。资源包的 UUID、版本和包内文件均保留；更新材质时请同步提高 manifest 版本和世界引用版本。

### 为什么此前会卡住

首轮 iOS 客户端收到后端列表后直接回复“已有全部资源包”，没有实际请求下载。后续诊断由桥接端请求 BDS 发送下载任务，iOS 开始请求分片，却没有再次发送完成响应，导致 BDS 一直等待。当前实现会等待所有包的分片转发完成，在可靠连接上给客户端短暂的解包时间，再恢复最初的完成响应。完整原生组件预加载上下文也必须保留；仅修复分片衔接不足以让独立后端包加载。重复、乱序或不完整分片不会使协商提前结束，断线会取消尚未发送的响应。

这是资源传输的兼容处理，不伪造材质已渲染的结果。Debug 中的分片和完成日志可用于诊断，游戏最终显示仍需客户端验证。

## Aplok Guns 1.1.8：网易玩家透明

已在一套包含 7 个资源包的测试世界中确认：Aplok Guns 1.1.8 的 `minecraft:player` 客户端实体覆盖会使网易玩家第三人称皮肤透明。保留枪械资源包、仅停用枪械行为包不能解决；移除资源包里的 `entity/player/ster1ee3ad78.json` 后皮肤恢复。用户同时确认枪械测试正常。这个结论仅适用于已测试的组合，不代表所有枪械动作、HUD 或其他版本均兼容。

仓库提供一个可选工具，为这份已知资源包生成独立兼容副本；桥接程序不会自动删除资源，也不会改写后端原包。工具只移除上述玩家实体定义和对应的 `contents.json` 条目，保留其他文件，并提高包版本以避免旧缓存。

停止测试服后，在仓库目录执行（需要 Python 3）：

```sh
python scripts/prepare_aplok_netease.py "原枪械资源包目录" "新的兼容资源包目录" --version 1.1.12
```

将新目录安装为后端使用的资源包，同时把世界 `world_resource_packs.json` 中 UUID `d6067ec8-4a70-467b-85c2-a43b8be9cebc` 的版本，以及枪械行为包 manifest 中对该 UUID 的依赖版本，更新为 `1.1.12`。同一个 UUID 只安装、启用一份资源包；保留原包备份时应移到 BDS 扫描目录之外。重新启动后端并重新开桥接房间。

该处理会停用枪械包对玩家实体的自定义渲染入口，可能影响其他玩家动作或 HUD；请在测试副本中检查网易及国际版客户端，再用于正式服。当前已验证网易皮肤和用户测试的枪械操作正常，尚未完成国际版客户端对照。它不是通用材质转换器，不会分发第三方资源文件。

## 导入原生房间的组件配置（高级，可选）

默认经典材质不需要此步骤。仅在希望替换预加载组件时使用；导入成功会设置 `netease_resource_packs: true`，有效的自定义文件会覆盖内置经典材质。要切回经典材质，停止房间，在 `config.json` 中改为 `netease_resource_packs: false`，重新启动程序即可，不必删除文件。

1. 在网易客户端为一个原生世界启用目标材质，创建无密码的本地联机房间，记下房间号。机器人需要有加入该房间的权限。
2. 停止使用同一机器人账号的所有桥接房间，包括其他电脑上的实例。保留 NEMCBridge 原有配置和令牌。
3. 在程序目录执行下面的导入命令。程序使用第一个机器人令牌读取原生房间的资源元数据，然后离开；不进入世界，也不复制世界或材质文件。

Windows PowerShell：

```powershell
.\NEMCBridge.exe -import-resource-room 123456
```

Linux / macOS：

```sh
./NEMCBridge -import-resource-room 123456
```

使用自定义数据目录时，沿用原来的 `-data-dir` 参数。有房间密码时追加 `-resource-room-password "房间密码"`。

4. 成功后，程序在数据目录生成 `netease-resource-profile.json`，并开启 `netease_resource_packs`。重新启动程序并开房，网易玩家加入时会先处理该房间声明的组件。
5. 检查实际贴图/UI，并退出后重新加入验证。后端材质会自动加载。自定义预加载失败时，可按上述方式将 `netease_resource_packs` 改为 `false`，切回默认经典材质。

导入工具目前适配游戏协议 860、网易字典压缩的原生房间；需要验证服务器在登录响应中提供数字组件编号。原生房间或组件更新后，应重新导入。多房间共用同一份资源配置。

## 保存与部署

`netease-resource-profile.json` 含服务器提供的资源包内容密钥，使用私有文件权限保存，已加入 Git 忽略规则；不要提交到公开仓库或放入发行压缩包。可随自己的数据目录迁移到另一台机器，管理接口只返回是否启用，不返回资源配置内容。

内置经典材质元数据已编译进程序，普通部署无需额外文件。JSON 参数 `netease_resource_packs` 为 `true` 且导入文件存在时优先使用该文件；缺失时回退经典材质，存在但损坏/不可读时报告错误。加载后端材质时合并预加载组件与后端包列表，并保留原生扩展。后端依赖资源包定义的自定义方块、实体和脚本仍需单独适配，导入元数据不会将网易行为包逻辑安装到 BDS。

## 下载完成却进不去

客户端下载组件时可能错过最初的服务器就绪通知。程序在等待连接时会有限补发通知，在连接建立、玩家离开或房间关闭后停止。完整 Debug 日志可区分组件下载前、WebRTC 连接和游戏资源包协商阶段；下载完成提示本身不代表贴图已成功加载。
