01 · HOW IT WORKS

一座桥，连接两套协议

网易玩家通过本地联机房间连接 NEMCBridge，桥接完成身份映射与协议转换，再接入 BDS 或通过 Geyser 进入 Java 世界。基岩版与 Java 版玩家直连对应的服务器。

02 · FEATURES

开好房，就交给它

从方块交互到好友申请，房主需要守在电脑前做的事，NEMCBridge 都替你做了。

真正的共同游玩

支持 BDS 与 Geyser 协议 860 原版方块表，可接入基岩版或 Java 服务器。区块加载、方块交互、双向聊天、皮肤互显与后端材质包同步，网易玩家按账号拥有独立存档。

房主常驻

机器人保持房间连接，掉线后按设定间隔（5–300 秒）自动重新开房。

自动加好友

房间在线时每 30 秒检查并同意待处理的好友申请，失败独立退避，不影响房间。
