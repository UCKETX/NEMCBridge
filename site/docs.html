快速开始

准备好自己的 Bedrock Dedicated Server，然后跟着做。

  1. 1

    准备后端

    运行支持版本的 BDS（网易安卓已在 26.20 / 26.60 实机验证主要流程），在 server.properties 中设置：

    online-mode=false
compression-algorithm=zlib
block-network-ids-are-hashes=true

    后端使用离线身份，请自行配置防火墙与访问权限。

    26.50 / 26.60 的已测 BDS 使用 NetherNet，需设置 transport=nethernet，桥接地址填写 http://主机:信令端口，并放通对应 UDP 端口；旧版 RakNet 仍填写 主机:UDP端口。Geyser 和其他实现请按完整部署指南及下方兼容性说明配置。

  2. 2

    下载并启动

    在下方 下载 一节选择对应系统与架构的压缩包。

    解压 windows_amd64.zip，双击 NEMCBridge.exe 即可。

    # 或在 PowerShell 中指定数据目录
.\NEMCBridge.exe -data-dir .\data

    x86 服务器选 amd64，ARM 服务器选 arm64。

    tar -xzf NEMCBridge_*_linux_amd64.tar.gz
cd NEMCBridge_*_linux_amd64
chmod +x NEMCBridge
./NEMCBridge -data-dir ./data

    Apple Silicon 选 arm64，Intel 芯片选 amd64。

    tar -xzf NEMCBridge_*_macos_arm64.tar.gz
cd NEMCBridge_*_macos_arm64
chmod +x NEMCBridge
./NEMCBridge -data-dir ./data
  3. 3

    登录并开房

    打开 http://127.0.0.1:18321/，用 admin 和终端显示的首次密码登录。填写 FGAuth 验证服务器、你的机器人令牌和后端地址，保存后点击「开房」。

    桥接会按后端版本自动下载、校验并缓存新版内容的兼容外观包，再下发给网易玩家。服主无需向 BDS 世界安装兼容包，玩家无需手动导入。后端已有的资源包也会转发；首次加入请等待下载和加载完成。

BDS 已验证的主要流程

以下包含网易安卓在 BDS 26.20 / 26.60 上的主要流程反馈，不代表所有后端或版本均通过实机验收。

  • 进入世界、地形加载、背包与主要建筑交互
  • 新增物品配方、燃料、容器、展示框及盆栽
  • 资源自动下载、缓存及重新进服加载
  • 独立账号存档、重连恢复服务端确认的 OP 权限
  • 硫方怪内芯、装桶，以及 Bounce 播放与停播

仍有兼容限制

  • 白杨船放下后采用白桦船体；稻草床可能短暂显示红床
  • 层架蘑菇弹跳为近似补偿，部分区域移动抽动仍待完善
  • 硫方怪 TNT 闪白与膨胀未启用；冰系与唱片压制机界面不在本版范围
  • 任意行为包、脚本、复杂 UI 与自定义皮肤不保证兼容

Geyser（实验性）

已验证协议 859 / 860 / 898 / 924 / 944 / 975 / 1001 / 2168 / 2169 / 2193 / 2225 的原版顺序方块表，覆盖所列 1.21.120–26.60 版本。5 个官方 Geyser 构建配合独立 Purpur 后端，11 档协议的直连与 WebRTC 共 22 条链路通过登录、资源协商、世界与完整区块、创造物品注册、中文/emoji 聊天及连续动作后的命令回执验证。

测试关闭了 Geyser 自定义内容、集成资源包与 Bedrock 正版验证，并使用 Java 离线认证。桥接目标应填写 Geyser 基岩入口；Geyser 须接受探测响应中声明的协议，生产连接不会遍历协商其他版本。任意自定义方块、扩展顺序表及 blob 缓存仍不支持。Java 玩家直连 Java 服务端，NEMCBridge 本身不接收 Java 客户端连接。

其他基岩服务端

以下固定构建均通过直连与 WebRTC 的登录、资源协商、地形、聊天、背包创造取物、槽位转移和重连保存验证；Dragonfly 未断言通用命令系统。历史构建主要验证世界与聊天基线，不能一概视为完整背包回归通过。

  • 协议 1001：Allay 0.14.0、PocketMine-MP 5.44.3；这两个已测构建不支持更高协议。
  • 协议 2225：PowerNukkitX 3.0.6、Nukkit snapshot 1252、Nukkit-MOT 1766、Cloudburst snapshot 162、Dragonfly（报告固定提交）。
  • 协议 2225：Endstone 0.11.15 + BDS 26.60.6、LeviLamina 26.60.4 + Windows BDS 26.60.6。

Nukkit 2168+ 需在国际服设置中选择「Nukkit」兼容配置，或为该服务端设置 compatibility_profile: "nukkit"；默认 auto 不会主动套用此差异。其他实现按各自配置方式设置，不应直接套用全部 BDS 选项。

部分历史构建存在例外：Cloudburst 924 无法启动，944 / 975 / 2193 存在上游聊天故障；旧 PowerNukkitX 2.0.0 官方产物实际声明协议 1001，不能作为 975 通过的证据。LeviLamina 已验证 8 档官方组合及背包重连；924（26.0）和 2169（26.45）无匹配官方发行组合，未实服验证，不计为通过或桥接失败。

上述 Geyser 与其他服务端自动化测试主要使用合成网易 898 协议客户端连接真实服务端，不能替代真实网易手机客户端验收。Geyser 的渲染、移动、挖放、背包与骑乘仍待实机验收；其他实现也尚未逐版本覆盖合成、碰撞、实体交互、强制资源包及第三方内容。已有 BDS 手机反馈不能推定为其他服务端也已通过。

自动外观资源

玩家进服自动加载，服主无需手动放兼容包。

  1. 桥接识别房间的后端协议，选择对应的已发布外观资源包。
  2. 首次使用时联网下载，检查大小和 SHA-256，再存入数据目录的 cache/appearance/。
  3. 网易玩家加入时，由桥接完成资源协商与下发；有效缓存可重复使用，无需每次重新从 GitHub 下载。

兼容外观包独立于可执行文件发布，不需要上传网易，也不需要导入开发工具。国际版玩家直接连接 BDS，不经过这条下发路径，不会因此多出一套新增物品。

服务器自己的资源包仍需由服主在后端安装并启用。自动兼容包只补齐已适配内容，并不代表任意资源包、行为包和实验功能均可运行，也不会自动开启世界实验。

常见问题

提示「客户端与房主版本不同」？

先核对上方的兼容版本表。网易客户端版本、房间版本及后端游戏协议需要分别匹配；修改服务器 MOTD 无法代替协议适配。房间版本字段与 BDS 版本是两个独立配置，不要按后端版本随意替换。

房间反复断开怎么办？

确认同一机器人账号没有被其他程序、设备或客户端重复登录。本机相同用户、相同令牌有会话锁，但无法阻止其他设备。检查日志中的信令、鉴权及网络错误；自动重连不保证保留原房间号。

能加入房间，但进不了世界？

检查 BDS 地址、端口、版本，以及 online-mode、压缩算法和方块 ID 设置。提交问题时附上已脱敏的连接阶段日志和双方完整版本号。

看不到皮肤？

国际版尝试关闭「仅允许受信任的皮肤」并让双方重新加入。特殊商城、4D 或自定义模型不保证兼容；若只在启用某个材质包后异常，请检查该包对玩家模型和渲染的覆盖。

如何让网易玩家加载服务器材质包？

新版内容兼容包由桥接自动下载和下发，详见自动外观资源。如果是你自己选择的服务器材质包，仍需在 BDS 世界中安装并启用；更新后提高包与世界引用的版本，并重启后端、重新开房。复杂 UI、行为包及脚本需单独验证。

需要自己准备哪些东西？

你需要自行运行兼容的基岩服务端，或 Java 服务端与 Geyser，并准备 FGAuth 验证服务器及属于自己的房主机器人令牌。本项目不附带账号、令牌或服务器程序。令牌会发送到你所选的验证服务，请使用自己信任的服务。

如何远程管理服务器上的 NEMCBridge？

控制台默认使用 HTTP，请用防火墙把 18321 端口限制在可信网络内。远程服务器推荐用 SSH 转发：ssh -N -L 18321:127.0.0.1:18321 user@your-server，然后在本机打开 http://127.0.0.1:18321/。
