文档

从准备服务器到让第一位朋友进房，需要知道的都在这里。

快速开始

准备好自己的 Bedrock Dedicated Server，然后跟着做。

  1. 1

    准备后端

    运行 BDS（已验证 1.21.124.2），在 server.properties 中设置：

    online-mode=false
compression-algorithm=zlib
block-network-ids-are-hashes=true

    后端使用离线身份，请自行配置防火墙与访问权限。

  2. 2

    下载并启动

    在下方 下载 一节选择对应系统与架构的压缩包。

    解压 windows_amd64.zip，双击 NEMCBridge.exe 即可。

    # 或在 PowerShell 中指定数据目录
.\NEMCBridge.exe -data-dir .\data

    x86 服务器选 amd64，ARM 服务器选 arm64。

    tar -xzf NEMCBridge_*_linux_amd64.tar.gz
cd NEMCBridge_*_linux_amd64
chmod +x NEMCBridge
./NEMCBridge -data-dir ./data

    Apple Silicon 选 arm64，Intel 芯片选 amd64。

    tar -xzf NEMCBridge_*_macos_arm64.tar.gz
cd NEMCBridge_*_macos_arm64
chmod +x NEMCBridge
./NEMCBridge -data-dir ./data
  3. 3

    登录并开房

    打开 http://127.0.0.1:18321/，用 admin 和终端显示的首次密码登录。填写 FGAuth 验证服务器、你的机器人令牌和后端地址，保存后点击「开房」。

    网易「本地联机」搜索控制台显示的房间号
    国际版添加服务器：BDS 地址 + UDP 端口

已验证

  • 地形与子区块加载、走动、破坏和放置方块
  • 普通成员权限，OP 降回成员后保留建造能力
  • 按网易账号隔离存档，改名重连保留背包与位置
  • 双向文字聊天（含中文与 emoji）
  • 命令转发与回执，错误命令后保持连接
  • 玩家皮肤互显
  • 最大 32 MiB 解压批次与超过 255 个 WebRTC 分片

当前限制

  • 网易端跳过服务端资源包与行为包，依赖包的自定义内容可能无法显示
  • 商城、4D、动画或自定义几何皮肤不保证兼容
  • 重新开房后房间号可能变化
  • 不支持 Java 版客户端

常见问题

提示「客户端与房主版本不同」？

先核对上方的兼容版本表。网易客户端版本、房间版本及后端游戏协议需要分别匹配；修改服务器 MOTD 无法代替协议适配。房间版本字段与 BDS 版本是两个独立配置，不要按后端版本随意替换。

房间反复断开怎么办？

确认同一机器人账号没有被其他程序、设备或客户端重复登录。本机相同用户、相同令牌有会话锁，但无法阻止其他设备。检查日志中的信令、鉴权及网络错误；自动重连不保证保留原房间号。

能加入房间，但进不了世界？

检查 BDS 地址、端口、版本，以及 online-mode、压缩算法和方块 ID 设置。提交问题时附上已脱敏的连接阶段日志和双方完整版本号。

看不到皮肤或资源包内容？

国际版尝试关闭「仅允许受信任的皮肤」并让双方重新加入。网易端目前跳过后端资源包，不能依靠服务器下发包来显示自定义内容；特殊商城、4D 或自定义模型不保证兼容。

需要自己准备哪些东西？

你需要自行运行 Bedrock Dedicated Server 和世界，并准备 FGAuth 验证服务器及属于自己的房主机器人令牌。本项目不附带账号、令牌或服务器程序。令牌会发送到你所选的验证服务，请使用自己信任的服务。

如何远程管理服务器上的 NEMCBridge？

控制台默认使用 HTTP，请用防火墙把 18321 端口限制在可信网络内。远程服务器推荐用 SSH 转发：ssh -N -L 18321:127.0.0.1:18321 user@your-server，然后在本机打开 http://127.0.0.1:18321/。
